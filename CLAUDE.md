# Sadeh Studio — Project Context

## What This Site Is

A professional landing page for Sadeh Studio, an independent consultancy co-founded by Tal Sadeh (architect/urban designer) and Dor Sadeh (software engineer), based in Alicante, Spain.

## Tech Stack

Vanilla HTML + CSS + JavaScript. No build tools, no frameworks, no dependencies. Single `index.html` + `styles.css`. Deploy as static files.

### About
Sadeh Studio is an independent consultancy founded at the intersection of two disciplines that rarely share a common language — architecture and software engineering. We help research institutions and public-sector organisations extract meaning from complex built environment data: reading it, structuring it, and making it genuinely accessible.

Our work combines professional knowledge of planning systems and the built environment with the technical capacity to build intelligent, data-driven tools around that knowledge.
